# OpenInterviewer 5.4.4

A maintenance release with routine dependency updates. Nothing changes for
researchers or participants.

## What changed

- **Runtime patches.** React 19.3.1, jose 6.2.15 (session and sign-in
  tokens), the Upstash Redis client 1.41.0, the Redis client 6.3.1 and
  zustand 5.0.16.
- **Development toolchain.** Playwright 1.64.1, Tailwind CSS 4.3.4, the Vite
  React plugin 6.2.1 and jsdom 30.1.3. Vitest is held at 5.0.3, because 5.1
  breaks the Cloudflare Workers test runtime.
- **AI provider SDKs are unchanged.** Their update waits for a live provider
  check.

## Upgrade and rollback

A code-only release, with no schema, configuration or binding changes. Rolling
back to 5.4.3 is safe.
