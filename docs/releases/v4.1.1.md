# OpenInterviewer 4.1.1

A maintenance release on top of [4.1.0](v4.1.0.md): self-hosted fonts,
dependency updates and a README for the Cloudflare stack. No behaviour change
for researchers or participants.

## Build

- **Self-hosted fonts.** Source Serif 4, Public Sans and IBM Plex Mono are now
  in the repository (`src/fonts/`, SIL Open Font License), so a build never
  downloads from Google Fonts. CI builds had failed intermittently on that
  download. The served font files are byte-identical to 4.1.0's.
  ([#58](https://github.com/linxule/openinterviewer/pull/58))

## Dependencies

- Next.js 16.3.5 (backported bug fixes), with `@upstash/redis` 1.39.0,
  autoprefixer 10.6.1, jsdom 30.1.1 and Tailwind CSS 3.4.19.
  ([#53](https://github.com/linxule/openinterviewer/pull/53))
- Provider SDKs: `@anthropic-ai/sdk` 0.127.0, `@google/genai` 2.24.0,
  `@openrouter/sdk` 1.3.17, `ai` 7.0.109, `openai` 7.21.0.
  ([#49](https://github.com/linxule/openinterviewer/pull/49))
- Dependabot no longer proposes `@types/node` major versions; they move with
  the pinned Node runtime (24.19.0).
  ([#59](https://github.com/linxule/openinterviewer/pull/59))

## Documentation and tests

- The README leads with the Cloudflare target the project now runs, and
  describes the project's own instance as installer-deployed.
  ([#57](https://github.com/linxule/openinterviewer/pull/57))
- The paid provider smoke now prints its metadata line when run by a coding
  agent, where Vitest had hidden it.
  ([#60](https://github.com/linxule/openinterviewer/pull/60))

## Upgrade notes

- No configuration change on either target. A Cloudflare installation updates
  with `npm run setup:cloudflare -- update`.

## Verification

`npm run check:cloudflare` (the full release matrix) on the release commit.
The paid provider smoke passed for Gemini, Claude, OpenAI and OpenRouter on
the new SDKs: one synthesis call each, direct transport, synthetic data.
