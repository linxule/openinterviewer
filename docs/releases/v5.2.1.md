# OpenInterviewer 5.2.1

A build-tooling release on top of [5.2.0](v5.2.0.md): Tailwind CSS 4. No
schema, configuration or consent-copy change; researcher and participant pages
look the same as in 5.2.0, with one small spacing fix.

## Browser support

Tailwind CSS 4 needs [Chrome 111, Safari 16.4 or Firefox 128](https://tailwindcss.com/docs/compatibility).
Next.js 16, which OpenInterviewer has used since 2.0, already targets Chrome 111,
Edge 111, Safari 16.4 and Firefox 111, so the only change is Firefox 111-127.
In a browser that applies none of the styles, the participant pages are plain
but still work: a test run with every stylesheet blocked consented, answered
and saved.

## Changes

- **Tailwind CSS 4** (`@tailwindcss/postcss`; `tailwind.config.ts` is replaced
  by the `@theme` block in `src/app/globals.css`) and **tailwind-merge 3**.
- Pages were compared pixel by pixel against 5.2.0 at desktop and phone widths
  (researcher pages, study tabs, edit mode, interview detail and analysis, the
  participant consent, interview, completion and saved screens). The one
  intended difference: "Start from a preset" in the setup page now has the same
  gap above it as the other fields. Unknown pages now show a styled
  "Page not found" page instead of the framework default.
- The dismissed postcss-selector-parser alert no longer applies: the package
  left the dependency tree with Tailwind 3.

## Release check

The `braces` audit exception (GHSA-vfj7-8cjw-p6xm, no patched release) now
reaches the toolchain only through `eslint-config-next` (`fast-glob`,
`micromatch`), a lint-time path over this repository's own files. Its reason
is updated and it expires on 2026-11-24 (the check allows at most 45 days per entry). Production dependencies have no
exceptions.
