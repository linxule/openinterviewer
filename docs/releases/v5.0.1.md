# OpenInterviewer 5.0.1

A security release on top of [5.0.0](v5.0.0.md). No behaviour change for
researchers or participants, and no schema or configuration change.

## Security

- **Next.js 16.3.8.** Fixes GHSA-vcvr-r3jv-pc5j (critical: remote code
  execution in `next/og` `ImageResponse`) and the cache-poisoning,
  Image Optimization SSRF and metadata-route advisories that affect 16.3.7 and
  earlier. OpenInterviewer does not import `next/og`, but the framework module
  ships in the bundle, so every installation should update.
- **sharp 0.35.5** (CVE-2026-96889 in its bundled librsvg), forced with an
  `overrides` entry because miniflare pins 0.35.4. The transitive
  `brace-expansion` and `source-map-js` copies are updated too.

`npm audit --omit=dev` is clean.

## Release check

The `audit-toolchain` lane now runs `scripts/cloudflare/audit-toolchain.mjs`.
It still fails on any high or critical development advisory, except one listed
in `scripts/cloudflare/audit-exceptions.json` with a reason and an expiry date;
an expired entry fails the release. The single entry is `braces`
(GHSA-vfj7-8cjw-p6xm), which has no patched release and reaches only the build
and lint tools through Tailwind CSS 3, fast-glob and the Next.js ESLint plugin.
It expires on 2026-11-08. Production dependencies have no exceptions.

## Upgrade notes

- Cloudflare: `npm run setup:cloudflare -- update`. Node: redeploy as usual.
- Compatible in-place with 5.0.0 in both directions.
