# OpenInterviewer 5.4.5

A maintenance release that updates the AI provider libraries. Nothing changes
for researchers or participants.

## What changed

- **AI provider SDKs.** Google Gen AI 2.32.0, the OpenRouter SDK 1.5.45, the
  OpenAI SDK 7.50.0 and the AI SDK 7.0.162 (used for the AI Gateway route).
  A live check against Gemini passed; the OpenAI and OpenRouter routes are
  covered by the test suite only in this release.

## Upgrade and rollback

A code-only release, with no schema, configuration or binding changes. Rolling
back to 5.4.4 is safe.
